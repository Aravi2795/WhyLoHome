## 🚀 Instant Deployment to Vercel

You can deploy this website to **Vercel** for free in under 60 seconds using any of the three methods below:

### Option 1: Drag & Drop via Vercel Web Dashboard (Fastest — No CLI or Git required)
1. Go to **[vercel.com](https://vercel.com)** and log in or sign up with GitHub / Google / Email.
2. Click the **"Add New..."** button and choose **"Project"**.
3. Drag and drop this folder (`kms-tours`) into the upload box on the Vercel dashboard.
4. Click **Deploy**. Vercel will instantly generate a live URL (e.g., `https://kms-travels.vercel.app`).

---

### Option 2: Deploy via GitHub (Recommended for continuous deployment)
1. Initialize git and commit this repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for KMS Travels"
   ```
2. Create a new repository on [GitHub](https://github.com/new).
3. Link and push to GitHub:
   ```bash
   git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
   git branch -M main
   git push -u origin main
   ```
4. On **[vercel.com/new](https://vercel.com/new)**, click **"Import"** next to your GitHub repository.
5. Click **"Deploy"**. Any future changes you push will automatically update your live site!

---

### Option 3: Deploy via Vercel CLI
1. Open your terminal or PowerShell and run:
   ```bash
   npx vercel
   ```
2. Follow the quick prompts to log in and select default settings.
3. To deploy directly to production:
   ```bash
   npx vercel --prod
   ```
